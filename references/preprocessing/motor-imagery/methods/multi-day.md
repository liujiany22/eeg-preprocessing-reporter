# Multi-day high-quality MI 预处理与技术验证流程

对应论文：*A multi-day and high-quality EEG dataset for motor imagery brain-computer interface*。

## 方法边界

- 本流程复现该数据集论文的预处理和时频空技术验证，不是通用坏道、ICA 或自动坏 Trial 流程。
- 论文专属的 Pz 参考、4 s Epoch、50 Hz 工频处理和 1000→250 Hz 降采样，只有当前数据支持且确实执行时才能写入结果；否则标为不适用或方法偏离。
- 原论文未报告的步骤不得混入论文复现分支；确需增加时另建“偏离原方法”分支，不把其结果标为论文流程。

## 预处理操作流程

1. 数据提供采集阻抗时，核查实际阻抗并以“尽量低于 5 kΩ”作为原论文采集目标；没有阻抗记录时标为资料未提供，不从 EEG 反推。
2. 移除实际存在但未记录有效信号的 ECG、EOG 等非 EEG 通道。用 Pz 重参考时记录重参考前通道数，并明确 Pz 是否从输出通道中移除。
3. 使用与论文相符的 FIR 实现执行 0.5–40 Hz 带通和 50 Hz 工频抑制；记录 MNE 实际 filter design、transition bandwidth、filter length、phase 和工频实现，不能只写截止频率。
4. 按真实 Cue 和 Trial 边界截取论文定义的 4 s 运动想象 Epoch；使用真实基线区间做 Epoch 基线校正，再从 1000 Hz 降采样到 250 Hz。当前数据的范式、采样率或基线不同时记录偏离，不强行套用。
5. 不加入 ICA、自动坏道检测、插值或自动坏 Trial 剔除。若当前数据必须先处理这些问题，原论文分支标为不能直接执行；新增处理只放在独立偏离分支。
## 预处理报告输出

Multi-day 流程在预处理报告中只输出：

1. 执行状态、实际适用步骤、实际处理顺序与参数、相对论文流程的偏离。

## 质量评估步骤

1. 在 8–12 Hz 计算 ERD/ERS：带通 → 每采样点平方 → 同条件 Trial 平均 → 滑动窗平滑 → `(A-R)/R × 100%`。`R` 使用实际基线；没有有效基线时不计算。手部任务检查 C3/C4，足部任务检查 Cz，仅限实际存在的任务和通道。
2. 对预处理 Epoch 做 STFT，计算相对运动想象前基线的 ERSP，展示 8–30 Hz μ/β 范围；STFT 窗长、重叠、频率分辨率和归一化方式使用论文代码或明确记录的复现值。
3. 计算 CSP 并绘制空间模式或 Topography；只在标签和样本量支持的条件比较中执行。多分类时记录采用的 CSP 扩展方式。
4. 只有用户明确要求解码验证时，才按论文代码运行适用于当前任务的 CSP+SVM、FBCSP+SVM、EEGNet、DeepConvNet 或 FBCNet；训练与测试隔离，不把论文报告值当作当前数据结果。

## 质量评估报告输出

Multi-day 的实际结果放入运动想象质量评估模板第 3 节的对应方法小节，并按下列归属组织：

1. 执行状态、实际适用步骤、实际处理顺序与参数、相对论文流程的偏离。
2. 数据提供阻抗时，给出逐通道阻抗的数据集级摘要和超过 5 kΩ 的实际记录数；没有记录时只写未提供。
3. 各条件在实际感觉运动通道的组平均 ERD/ERS 曲线、ERSP 图和 CSP Topography 放入第 3.2.6 节“运动想象任务特异结果”；频带、基线、被试数、Session 数、Trial 数和聚合方式写入图注，不在方法特异结果中重复。
4. 阻抗结果和多 Session 数据中同一指标的跨 Session 配对结果放入第 3.2.7 节“方法特异结果”；只报告实际变化，不预写训练效应或质量改善。
5. 仅在实际执行解码验证时，把逐被试与 Session 的指标以及组摘要放入第 3.2.7 节；Chance level 按实际类别数和评估设计确定。

## 质量评估报告附录

以下内容放在质量评估报告附录的 Multi-day 明细中：

1. 数据提供阻抗时的逐被试逐通道阻抗图或表，并标出实际参考和接地；数据集只给示例阻抗图时，不扩展为全体统计。
2. 逐被试与 Session 的 ERD/ERS、ERSP 和 CSP 明细；正文只保留组级结果。
3. 所有实际计算参数和核心 MNE 代码，包括 FIR、Epoch、基线、降采样、STFT、ERD/ERS 和 CSP。
4. 执行解码验证时的逐被试、逐 Session 完整结果；未执行时不保留空白分类章节。

该分支支持的常规图和运动想象任务特异图按质量评估主模板组织，不在 Multi-day 方法特异明细中重复。

## 不生成的内容

- 不生成 Bad-channel metric 或 ICA 图；这些不是该论文流程。
- 不自动执行论文列出的全部分类器，不用论文准确率替代当前数据结果。
- 不因出现或未出现预期 ERD/ERS、ERSP、CSP 模式而自动排除被试；被试范围以数据集信息报告中的初步排除结果为准。
