# 模板使用规则（不写入最终报告）

- 除“模板使用规则”、`【中途确认，不输出】` 引用块和所有以 `【预处理注释，不输出】` 或 `【填写注释，不输出】` 开头的引用块外，其余标题、正文句子和表头属于预处理报告结构，应按模板保留。
- `{{……}}` 表示占位说明，必须替换为实际内容；不适用的可选占位内容应删除，最终报告中不得保留花括号及其中的说明文字。
- 每个预处理注释引用块只指导紧邻其上的模板内容；生成报告时连同注释标记整体删除。
- 预处理过程中需要生成的文件包括：预处理后的数据、质量评估中画图所需要的数据和材料等。生成的文件在文件夹内合适的位置保存。
