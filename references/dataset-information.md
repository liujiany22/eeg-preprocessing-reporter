# 数据集信息

按以下结构整理数据集信息，官方与本地表述不同则说明：

1. 数据集基本信息

   - 正式名称
   - 简称
   - 发布者
   - 发布日期
   - 官方页面
   - DOI
   - 许可
2. 任务

   - 说明数据集对应的任务，如情感识别、运动想象、癫痫诊断等。
3. 数据集文件结构

   - 展示数据集的文件与目录结构。
   - 表述文件概要信息。
4. 被试社会学信息

   - 论文或数据集提供相关信息时，整理被试人数、年龄、性别、健康状况等信息。
   - 论文或数据集提供相关图表时，结合原图或原表展示。
5. 采集参数

   - 整理采集设备、导联与电极布局、采样率、参考电极与接地，电极介质。
6. 实验范式

   1. 刺激材料：整理视觉、听觉、指示等刺激材料。
   2. 实验详细流程：清晰展示实验流程的全部内容及参数细节。论文或数据集提供流程图时，结合原图展示。
   3. Trigger 表：结合真实数据整理并展示 Trigger 表，覆盖全部 Trigger。
7. 被试集合与试次

   - 将实验流程相同的被试归为同一集合，并按“被试数 - 基线或静息段数 - 任务 A 试次数 - 任务 B 试次数 - ……”组织。
   - 表述试次内部结构，并与前述实验流程对应。
   - 表述试次对应测量的行为学指标。
8. 附录

   - 整理过程中未提及的异常、受限内容或其他重要内容。
